# Changelog

## Scripts

- `greet.sh` — prints `Hello, <name>!` for the first argument, or `Hello, world!` with none.
  Example: `./greet.sh Ana` prints `Hello, Ana!`.
- `test-greet.sh` — checks `greet.sh` for a named and an unnamed greeting; exits non-zero on any mismatch.
  Example: `./test-greet.sh`
